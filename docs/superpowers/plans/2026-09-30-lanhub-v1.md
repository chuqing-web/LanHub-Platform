# LanHub V1 Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax.

**Goal:** Ship a working WPF LanHub launcher + Core networking/crypto + SDK + Probe with full V1 UI and secure host-relay multiplayer plumbing (no games in library).

**Architecture:** Host relays encrypted room/SDK traffic; clients discover via UDP; games talk to local LanHub via SDK + launch token.

**Tech Stack:** .NET 8, WPF, UDP/TCP sockets, AES-GCM, HKDF, HMAC-SHA256
